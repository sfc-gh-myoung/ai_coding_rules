# AGENTS.md

Conventions for the root `Makefile`. Reference: [docs/USING_DEV_CLI.md](docs/USING_DEV_CLI.md).

## Help annotations

`make help` is generated by `awk` from the Makefile itself. No Python or other script.

| Annotation | Effect |
|---|---|
| `## @section Name \| note` | Starts a help section with an optional dim note |
| `## @quickstart cmd \| text` | Row in the Quickstart block |
| `## @example cmd \| text` | Row in the closing Examples block |
| `## @override VAR=value \| text` | Row in the Overrides block |
| `## @inputs VAR=x [OPT=y]` | Inputs of the next target (yellow) |
| `## @needs tools or cost` | Prerequisites of the next target (tools, credentials, AI credits) |
| `target: ## description` | Lists the target; keep it to one short line |

Put `@inputs`/`@needs` on the line directly above the target. Put the required inputs there, not in the description.

## Color and TTY rules

- Bold sections, cyan targets, yellow inputs, dim notes, green ok, red errors.
- Color is on only when the stream is a TTY and `TERM` is not `dumb`, or when `FORCE_COLOR`/`CLICOLOR_FORCE` is set. `NO_COLOR` always wins. Piped output has no escape codes.
- Use `$(call say,text,G)`, `$(call fail,text)` and `$(call colors,fd)` in recipes. `$(error)` messages (the `require` macro) are colored from stderr at parse time. Message arguments must not contain commas.

## Macros and flags

- `require`: `$(call require,VAR,usage)` stops when a variable is empty. `need`: `$(call need,tool,message)` stops with an install message.
- `shq`: `$(call shq,value)` single-quotes a value for the shell. Quote every user-supplied value.
- Recipes are silent (`.SILENT`); `V=1` or `VERBOSE=1` echoes commands.
- `DRY_RUN=1` previews release steps; `FORCE=1` skips cleanup prompts.
- Recursion uses `$(MAKE) $(SUBMAKE) target` (keeps `make -C`/`-f` working). Write `$(MAKE)` literally: `make -n` only recurses into lines that contain it. Release recipes must never contain `$(MAKE)`.

## Hygiene checklist

- `SHELL := /bin/bash` with `.SHELLFLAGS := -eu -o pipefail -c`. GNU Make 3.81 (macOS) ignores `.SHELLFLAGS`, so multi-step recipes also start with `set -eu`.
- `.SUFFIXES:`, `.DELETE_ON_ERROR:`, `--no-builtin-rules`, `--warn-undefined-variables`. Give every per-invocation variable a `?=` default.
- Every target is in `.PHONY` and has a `##` description. `make quality-makefile` (part of `quality-automation`) fails otherwise.
- No GNU Make 4.x features: the file must work on macOS Make 3.81.
