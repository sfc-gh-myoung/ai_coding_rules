# Security Policy

## Supported Versions

Security fixes are evaluated for the latest release on `main`.

## Reporting a Vulnerability

Do not report suspected vulnerabilities in public issues. Report privately through the repository's [GitHub Security Advisories](https://github.com/sfc-gh-myoung/ai_coding_rules/security/advisories/new) flow. If that flow is unavailable, contact the repository owner through the linked GitHub profile and request a private reporting channel.

Include reproduction steps, impact, affected version or commit, and any suggested mitigation. Maintainers will acknowledge the report, assess the impact, coordinate a fix, and agree on disclosure timing with the reporter.
